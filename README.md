# GenSports

Landing page responsive para GenSports, una tienda deportiva tipo outlet.

## Descripción

GenSports es una propuesta de tienda deportiva que ofrece ropa,
calzado y accesorios de grandes marcas a precios especiales.

Este proyecto fue desarrollado de manera colaborativa durante un hackatón.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap 


## Secciones principales

- Alerta de promoción y sorteo.
- Header y navegación.
- Contador de oferta.
- Banner de liquidación.
- Categorías deportivas.
- Catálogo deportivo.
- Beneficios de compra.
- Marcas participantes.
- Formulario de suscripción.
- Footer.
